# Interest pool — выплаты держателям после первого халвинга

> English version: [docs/INTEREST_POOL.md](INTEREST_POOL.md)

Этот документ описывает механизм перераспределения доли фонда в пользу
держателей монеты (interest pool) — так, как он реализован в консенсусе
сегодня, включая текущее ограничение и план его устранения. Документ
предназначен для бирж, аудитов и сообщества: здесь собраны все параметры,
которые проверяются по коду и состоянию цепи.

## 1. Две фазы распределения награды

### Фаза 1 — блоки 1 … 209 999 (активная)

10% от награды блока (block reward + комиссии транзакций) выплачивается
coinbase-выводом на адрес фонда:

- адрес: `GEOM3PyazNssCYYzF3tW9YrsSwszLq45QXbAZv`;
- политика: мультисиг **3 из 4**, адреса участников зафиксированы в
  `include/geocoin/consensus/consensus.hpp` (`FOUNDATION_*`);
- правило: `FOUNDATION_REWARD_PERCENT = 10` («правило 90/10»);
- генезис-награда направляется на тот же адрес.

### Фаза 2 — с блока 210 000 (первый халвинг)

С высоты `INTEREST_POOL_ACTIVATION_HEIGHT = 210 000` (совпадает с первым
халвингом: награда 50 → 25 GEO):

- доля фонда **больше не выводится coinbase-выводом** на мультисиг;
- она начисляется во внутренний **interest pool** — метаданные состояния
  цепи (`interest_pool_balance_`), консенсусно валидируется при применении
  каждого блока (`src/geocoin/state/state_block.cpp`, ветка
  `is_foundation_reward_redirected_to_pool`);
- поток в пул после халвинга: 10% × 25 GEO = 2.5 GEO за блок.

Смысл: сеть перестаёт «собирать налог в фонд» и начинает **выплачивать
дивиденды своим держателям** — эмиссия снижается халвингом, а освободившаяся
доля возвращается экономике держателей.

## 2. Квартальное распределение

- Периодичность: `INTEREST_DISTRIBUTION_INTERVAL = 13 104` блока
  (91 день × 144 блока/день ≈ квартал при 10-минутных блоках).
- На квартальной высоте консенсус **требует** ровно одну транзакцию типа
  `INTEREST_DISTRIBUTION` (позиция — сразу после coinbase). Вне квартальной
  высоты такая транзакция запрещена; если обязательное распределение
  отсутствует, блок невалиден (`state_block.cpp`, секция
  INTEREST_DISTRIBUTION).
- Распределение детерминировано: каждая нода пересчитывает эталонные выходы
  и сверяет транзакцию с расчётом — майнер не может распределить пул «как
  хочет».

## 3. Правила расчёта выплат (`build_interest_distribution_outputs_`)

Реализация: `src/geocoin/state/state_foundation.cpp:236`.

1. Балансы берутся **по адресам на предыдущем типе цепи**. UTXO, созданные
   в высоте распределения, в расчёт не попадают — это барьер против
   фарминга: нельзя замайнить/отправить пыль в том же блоке и получить долю.
2. Выплата адреса пропорциональна его доле в суммарном балансе:
   `payout = pool × balance / total_balance` (точное целочисленное
   деление через 128-битный mul-div, без потери консенсуса).
3. Выплаты ниже пыльного лимита (`DUST_LIMIT = 0.00001 GC`) пропускаются —
   второй барьер против пыльных ферм из множества мелких UTXO.
4. Результат публикуется целиком или не публикуется вовсе: частичные
   выплаты невозможны, транзакция проходит полную консенсусную проверку
   формата перед включением.

## 4. Известное ограничение (честно) и план

Одна транзакция распределения вмещает не более `MAX_TX_OUTPUTS = 1000`
выходов. Если построить корректное распределение невозможно (число
подпадающих под выплаты адресов превышает 1000), функция построения
возвращает ошибку, и по текущей консенсус-логике распределение в этот
квартал **не происходит** — пул переносится на следующий квартал.

- Активация механизма — блок 210 000, что при 10-минутных блоках наступает
  примерно через 4 года после запуска мейннета: времени на устранение
  ограничения достаточно, и оно **не влияет на работающую сегодня фазу 1**.
- План до активации: распределение несколькими транзакциями в квартальном
  блоке (аналогично позиционированию текущей единственной транзакции) либо
  выбор топ-N адресов с переносом остатка пула на следующий период.
  Выбранный вариант будет зафиксирован в этом документе и ADR до
  `INTEREST_POOL_ACTIVATION_HEIGHT`.

## 5. Опорные числа

| Параметр | Значение |
| --- | --- |
| Начальная награда за блок | 50 GEO |
| Доля фонда | 10% (reward + fees) |
| Мультисиг фонда | 3 из 4, до блока 210 000 |
| Первый халвинг = активация interest pool | блок 210 000 |
| Награда после первого халвинга | 25 GEO (в пул — 2.5/блок) |
| Период распределения | каждые 13 104 блока (≈91 день) |
| Пыльный лимит выплаты | 0.00001 GC |
| Лимит выходов в транзакции распределения | 1000 (см. раздел 4) |
