# Прозрачность работы команды

> English version: [TEAM_TRANSPARENCY.md](TEAM_TRANSPARENCY.md)

Этот документ публично фиксирует, **кто и как распоряжается средствами
GeoCoin, и что с ними происходит**: управление фондом, статьи расходов,
механизм interest pool и способы проверить всё это самостоятельно. Он
написан для всех — держателей, майнеров, бирж и корпоративных клиентов, а не
только для ревьюеров конкретной биржи.

## 1. Кто управляет средствами фонда

Средства фонда принадлежат не «команде», а **мультисиг-адресу 3-из-4**.
Ни один участник — включая инициаторов проекта — не может переместить
средства в одиночку: для расхода нужны подписи минимум трёх из четырёх
ключей.

| Параметр | Значение |
| --- | --- |
| Адрес фонда | `GEOM3PyazNssCYYzF3tW9YrsSwszLq45QXbAZv` |
| Политика | 3 подписи из 4 (`FOUNDATION_M = 3`, `FOUNDATION_N = 4`) |
| Участники | Захардкожены в `consensus.hpp` (`FOUNDATION_PARTICIPANTS`) |
| Смена политики | Только консенсусной транзакцией `UPDATE_FOUNDATION_ADDRESS` с кворумом 3-из-4 |

Все параметры захардкожены в
`include/geocoin/consensus/consensus.hpp` и изменяются только через
консенсусный upgrade, а не решением «в кабинете».

## 2. Что получает фонд

- **Genesis-субсидию** — 50 GC на адрес фонда из genesis-блока мейннета;
- **10% награды каждого блока** (`FOUNDATION_REWARD_PERCENT = 10`) вместе с
  долями комиссий, на высотах 1–209 999.

Порядок величин: при награде 50 GC за блок фонд получает ~5 GC за блок
(плюс 10% комиссий). Аккумулированная сумма видна любому на
[explorer](https://explorer.geocoin.network/) по адресу фонда.

## 3. На что идут средства фонда

**1. Поддержка проекта (постоянная статья).** Инфраструктура и разработка:
сид-ноды и надёжность сети, block explorer, инструменты биржевой
интеграции, документация, аудиты безопасности.

**2. Передача genesis-блока и гео-пазлы.** Точка запуска сети —
**48.851583° N, 8.897278° E — Porsche Development Center, Weissach,
Германия** (Porschestraße): genesis-геотег мейннета указывает именно туда,
оттуда мы стартовали. Часть бюджета направляется на символическую передачу
genesis-блока команде разработки аэродинамики («крыла») в этом месте, а
также на серию геолокационных пазлов — механику вовлечения, построенную на
гео-привязке самой сети (GeoPoW, кадастровые геотеги). Это основной
двигатель роста сообщества.

**3. Первые корпоративные клиенты сайдчейнов.** Регистрация сайдчейна на L1
требует заблокированного депозитного обеспечения (`LOCK_DEPOSIT`). Фонд
субсидирует обеспечение первых корпоративных клиентов, снижая их порог
входа и создавая живое B2B-использование цепи.

**4. Ликвидность на биржах.** Отдельная доля — на ликвидность GEO-рынков,
включая заблокированную биржевую ликвидность листинговых пар.

## 4. Отчётность

- **Каждый расход фонда проверяется on-chain**: любой может открыть адрес
  фонда в explorer и увидеть входящие блок-субсидии и исходящие траты.
- Значимые расходы (листинги, субсидии корпоративных депозитов, аудит)
  команда дополнительно публикует в [Discussions
  организации](https://github.com/NoemaCrypt/.github/discussions) — с
  txid и кратким описанием.
- В этом документе нет обещаний «фонд потратит N% на X» без on-chain
  подтверждения: документ описывает назначение статей, а факты — смотрят
  на explorer.

## 5. Interest pool — после первого халвинга доля фонда идёт держателям

С блока **210 000** (первый халвинг) 10%-доля фонда перестаёт выводиться
на мультисиг и консенсусно накапливается во внутреннем **interest pool**,
а каждые **13 104 блока (≈ квартал)** детерминированно распределяется
пропорционально балансам всех держателей:

- UTXO высоты распределения не учитываются — нельзя «намайнить» долю в
  последнем блоке;
- выплаты ниже пыльного лимита (0.00001 GC) пропускаются — пыльные фермы
  не работают;
- распределение обязательно по консенсусу и одинаково считается каждой
  нодой.

Полная механика, параметры и известное ограничение с планом устранения:
[INTEREST_POOL_RU.md](INTEREST_POOL_RU.md) (EN:
[INTEREST_POOL.md](INTEREST_POOL.md)).
